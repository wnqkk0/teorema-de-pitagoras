# Teorema de Pitágoras

Programa em Python que calcula a hipotenusa de um triângulo retângulo a partir dos dois catetos, usando o Teorema de Pitágoras.

## Fórmula

c = √(a² + b²)

## Como rodar

```
python pitagoras.py
```

O programa vai pedir o valor dos dois catetos e mostrar a hipotenusa calculada.
